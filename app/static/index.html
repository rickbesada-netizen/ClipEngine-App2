Post to YouTube

  1. Make an upload batch. Up to 15 new clips are copied into a folder, each file named with its finished title, so YouTube fills in every title for you.
  2. Upload them all at once. Open YouTube Studio, press Create, then Upload videos, select every file in the folder, and publish.
  3. One time only: in Studio go to Settings, Upload defaults, and paste this into Description and Tags, so every upload gets the campaign hashtags automatically.

  4. Done. Clip Engine checks your channel every 3 minutes, finds each new Short, fills in its link and starts the Whop countdown.

Profile pictures and banner

Use one profile picture on all three apps, and the banner on YouTube (Studio, Customisation, Branding). Once you've made clips for this campaign, one picture is built from a real frame. If the campaign gives you official artwork or a thumbnail, that's the safest choice.

Put it on your YouTube channel automatically Sets the banner you picked, the channel description and the keywords below in one go. YouTube doesn't let apps change the profile picture, so for that press Save picture, then open Studio, Customisation, Profile and upload it (about 20 seconds).
